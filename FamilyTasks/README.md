# Family Tasks

SwiftUI iOS app for sorting household tasks into the four urgent/important buckets.

## Calendar Sync

The app uses EventKit. If a Google account is added under iOS Settings > Calendar > Accounts, tasks are synced to a writable Google calendar when available.

## Family Sharing

The app includes a CloudKit share sheet entry point for inviting family members to a shared task list. Before running on device, replace the placeholder bundle identifier and iCloud container with values from your Apple Developer account.
